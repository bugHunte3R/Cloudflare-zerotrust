# Screenshots

Recommended sanitized screenshots:

- Zero Trust application list
- Access policy editor
- Identity-provider configuration overview
- Tunnel connector health
- Application authentication page
- Access denial page
- Audit-log overview
- Country or IP rule with values hidden

Before publishing, hide:

- Domains
- Subdomains
- Email addresses
- Account ID
- Zone ID
- Tunnel ID
- Application ID
- Policy ID
- IP addresses
- Identity-provider tenant information
- API tokens
- Service-token values
- Audit-log user information
- Browser notifications
- Personal application names

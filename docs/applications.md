# Protected Applications

## Application Categories

| Category | Recommended protection |
|---|---|
| Public portfolio | Public or light edge protection |
| Private dashboard | Access authentication |
| Portainer | VPN or strict Access |
| UniFi | VPN or strict Access |
| Nextcloud | Application authentication and optional Access |
| API | Service token and application authorization |
| Test application | Temporary Access policy |

## Application Inventory Practices

Document:

- Application purpose
- Owner
- Public hostname placeholder
- Origin service placeholder
- Authentication method
- Policy group
- Session duration
- Backup owner
- Recovery steps

Do not publish real hostnames or origins.
